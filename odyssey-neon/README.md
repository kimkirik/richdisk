# Odyssey Neon

[게임 실행](https://kimkirik.github.io/richdisk/odyssey-neon/)

기존 네온 슈팅과 300스테이지, BGM, 엔딩곡, 로컬 랭킹, 터치 자동발사를 유지한 갤러그 스타일 업데이트입니다.

- 기본 기체 크기 40% 축소. 첫 D는 두 기체가 나란히 동시 발사합니다. 두 번째 D는 세 기체를 하나의 큰 기체로 합치며, 모든 무기의 미사일 피해가 같은 강화 단계의 1기 대비 정확히 3배가 됩니다.
- 가장자리 공격 수정: 초합체 기체는 직전 버전보다 20% 작아졌고, 좌우 이동 여백을 줄였습니다. 적은 좌우 화면 안에서 되돌아오므로 모든 무기로 왼쪽·오른쪽 끝의 적을 공격할 수 있습니다.
- 주기적으로 D 구조선 출현. 격추 후 D 획득. 최대 합체에서 추가 D는 실드와 점수로 변환됩니다.
- `C` 또는 하단 무기 버튼: 관통 레이저 → 확산탄 → 폭발 미사일 → 유도탄.
- 4초 안에 다음 적을 격추해 콤보를 유지하면, 12킬마다 6초 오버드라이브가 켜집니다.
- 피격 시 실드, 합체 동료, 생명 순서로 보호합니다. 중앙의 흰 점이 피격 중심입니다.
- 전장 아래쪽까지 이동 가능하며, 오버드라이브 게이지는 전장 밖 조작 패널에 표시됩니다.
- 플레이 중 안내 메시지는 배경 박스 없이 작은 글자만 표시해 비행기와 적을 덜 가립니다.
- PC: 방향키/WASD 이동, **Z 또는 Space 발사**, **X 또는 B 폭탄**, **C 무기 변경**, **V 또는 Shift를 누른 채 이동하면 정밀 회피**, P 일시정지. 터치: 화면 드래그 이동, 자동발사.
- 초록 별 편대 5기가 V·파도·돌격 대형으로 등장합니다. 전멸 보상은 500점 × 합체 기체 수이며 D·M 아이템을 번갈아 확정 지급합니다. 피격 없이 연속 전멸하면 보상이 25%씩 올라 최대 2배가 됩니다. 적을 놓치거나 부딪혀 제거하면 전멸 보상을 받지 못합니다.
- 보스 광선은 위치를 고정한 뒤 1.2초 예고하고 0.5초 발사합니다. 붉은 선 밖으로 피하거나 폭탄으로 취소할 수 있습니다. 보스 체력 절반부터 2페이즈 탄막과 더 잦은 광선 공격이 시작됩니다.
- 일반 적의 기본 이동 속도는 최초 버전보다 약 12% 높습니다. 3스테이지부터 일반 적도 플레이어를 향해 사격하며, 가까이 접근한 적은 갑자기 발사하지 않습니다.
- 아이템 빈도를 소폭 낮췄습니다. 일반 드롭 확률은 12% → 10%, 정예 적의 폭탄 지급 확률은 100% → 80%입니다. 구조선 재등장은 18초 → 22.5초, 편대 재등장은 15초 → 18.75초이며 실패 후 재도전 대기도 25% 늘었습니다. 첫 구조선·편대와 보스 격파 보상은 유지합니다.
- 모든 보스의 시작·최대 체력을 직전 아케이드 버전보다 정확히 20% 늘렸습니다. 최종 보스는 4,290 → 5,148이며, 체력 비율에 따른 2페이즈 전환도 새 최대 체력을 기준으로 동작합니다.

| 무기 | 기본 1발 피해 | 발사 간격(60Hz) | 특징 |
| --- | ---: | ---: | --- |
| 관통 레이저 | 1.65 | 10틱 | 최대 3개 표적 관통, 좁은 직선 |
| 확산탄 | 0.7 | 12틱 | 강화에 따라 3·5·7갈래 부채꼴 |
| 폭발 미사일 | 3.4 | 24틱 | 직격과 주변 표적에 55% 폭발 피해 |
| 유도탄 | 1.35 | 18틱 | 살아 있는 전방 적을 향해 회전 |

M 강화 1단계마다 기본 피해의 40%를 더합니다. 최대 4단계이며 발사 수와 연사도 강화합니다. 2기 합체는 실제 발사 위치와 수에, 3기 초합체는 대형 기체와 3배 피해에 반영되며, 화면의 탄환 수 제한 때문에 공격력이 비정상적으로 증가하지 않습니다.

## 개발

외부 패키지 설치 없이 Node.js로 빌드·검사가 가능합니다. `src/app.js`는 기존 배포본에서 복원한 게임 UI와 루프, `src/combat.js`는 전투 규칙, `src/upgrade.css`는 추가 화면 스타일입니다. 기존 React 런타임은 `assets/react-runtime.js`로 분리하여 사용합니다.

```sh
npm test
npm run check
npm run build
python3 -m http.server 8876 --directory ..
```

빌드는 콘텐츠 해시가 포함된 배포 파일과 서비스 워커를 생성합니다. 소스 수정 후 `npm run build`를 실행하고 생성된 파일도 함께 배포하세요. 기존 배포 파일은 업데이트 중인 브라우저를 위해 보존합니다. 서비스 워커는 `odyssey-` 캐시만 관리하며 다른 앱의 캐시를 삭제하지 않습니다.
