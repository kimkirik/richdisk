개인정보와 무료 사용 안내

소라미는 로그인 없이도 이용할 수 있는 10개 언어의 가사 도우미입니다. 선택적으로 Google 계정에 로그인하면 Firebase 클라우드에 내 노래를 저장하고 다른 기기에서 불러올 수 있습니다. 앱 운영자의 Mac을 서버로 사용하지 않습니다.

기기에서 처리하는 것

일본어의 한글 발음은 기기에 다운로드한 Kuromoji 사전, 영어는 CMU 발음 사전과 한글 표기 규칙으로 만듭니다. 영어 사전은 약 4.4MB이며 필요한 경우에 내려받습니다. 사전은 약 17MB이며, 한 번 내려받은 파일은 브라우저가 보관할 수 있습니다. 추가 언어는 Pinyin Pro, 태국어 IPA 사전·보조 규칙, eSpeak NG 발음 분석으로 기기 안에서 처리합니다. 태국어 사전은 약 0.7MB, 추가 엔진은 대개 2–3MB, 러시아어는 약 9MB입니다. 언어 감지도 기기에서 처리하며 선택한 언어와 자동 번역 설정을 저장합니다. 최근 번역 캐시는 브라우저 localStorage에 최대 1,500개 저장됩니다. 불러온 노래의 곡명·가수·영상 ID·원문·발음·번역은 이 브라우저의 IndexedDB에 ‘지난 노래’로 저장됩니다. 선택적으로 넣은 웹 가사의 출처 주소도 노래와 함께 저장됩니다. 시간 없는 웹 가사의 안내를 보았는지도 기기에 저장합니다. 노래 목록은 곡 수 제한 없이 브라우저가 허용하는 저장 공간 안에서 보관되며 로그인하지 않은 기록은 다른 기기에 자동 공유되지 않습니다. 선택한 번역 엔진, 선택적으로 입력한 본인 이메일, 글자 간격, 직접 수정한 발음(최대 1,000줄), 영상·가사별 싱크 보정값도 이 브라우저에 저장됩니다. 시간 없는 가사의 자동 스크롤 간격은 마지막 설정을 localStorage에, 곡별 설정을 지난 노래에 저장합니다. 이 기능은 번역 요청을 보내지 않습니다. 이메일은 무료 번역 설정에서 체크를 해제하고 저장하면 삭제됩니다. 싱크 보정값은 초기화 버튼으로 지울 수 있습니다. 수정 발음은 해당 줄의 ‘자동 발음으로 되돌리기’로 삭제할 수 있습니다. 메인 화면의 ‘저장된 번역 지우기’는 최근 번역 캐시를 지우며 지난 노래 목록은 유지합니다. 브라우저 데이터 삭제 시에도 지워집니다.

Google 로그인과 노래 동기화

Google 로그인을 선택하면 Firebase Authentication이 계정 식별자, 이름, 이메일과 로그인 상태를 처리합니다. Google 비밀번호는 소라미가 받지 않으며 Gmail·Drive 파일을 읽는 권한은 요청하지 않습니다. 로그인 상태는 브라우저에 보관됩니다.

로그인한 뒤 불러오는 노래의 제목·가수·YouTube 영상 ID·가사 원문·발음·번역·출처·문맥 번역·언어 선택·싱크 보정·자동 스크롤 간격·저장 시각을 Cloud Firestore에 계정별로 보관합니다. 저장소는 서울 리전이며 같은 Google 계정으로 로그인한 소라미 웹 주소에서 읽을 수 있습니다. 다른 일반 이용자는 내 계정의 노래를 읽을 수 없도록 서버의 접근 규칙을 적용합니다. 서비스 운영자는 Firebase 관리 권한을 가지므로 종단간 암호화 저장소는 아닙니다.

로그인 전에 이 브라우저에 저장한 노래는 자동 업로드하지 않습니다. ‘이 기기 노래 합치기’를 누르면 현재 계정에 복사하며 원래 기기 기록을 유지합니다. 로그인 후 노래는 우선 기기에 저장되고 연결 가능할 때 클라우드로 전송됩니다. 저장이 끝나지 않은 곡은 다음 연결이나 같은 계정의 재로그인 후 재시도합니다. 번역 엔진의 이메일 설정·사진 파일은 동기화하지 않습니다.

로그아웃하면 앱에서 계정 목록과 현재 가사를 숨깁니다. 오프라인용 계정 사본과 업로드 대기 데이터는 이 브라우저에 남아 같은 계정으로 다시 로그인하면 사용할 수 있습니다. 공용 기기에서는 로그아웃한 뒤 브라우저 데이터를 삭제하세요. 클라우드에 보관된 정보는 브라우저 데이터 삭제로 없어지지 않습니다. 클라우드 기록 삭제는 서비스 운영자 kimkirik00@gmail.com으로 요청할 수 있습니다.

Firebase Spark 무료 범위로 운영하며 자동으로 유료 전환하지 않습니다. 프로젝트 전체 무료 한도에 도달하면 동기화가 일시 중단되고 기기에 저장합니다. 이는 번역 서비스의 글자 수·횟수 한도와 별개입니다. APK 가사창은 웹에서 내보낸 가사 파일을 받는 별도 앱이며 자체 Google 로그인은 제공하지 않습니다.

가사 사진 읽기

선택한 사진은 Tesseract.js로 이 기기에서 읽고 서버에 보내지 않습니다. 처음 일본어·영어 인식 파일 약 9MB를 내려받으며, 브라우저가 언어 파일을 보관할 수 있습니다. 확인한 원문을 발음으로 바꾸면 지난 노래에 글자만 저장합니다. 사진 파일은 저장하지 않습니다. 사진 가져오기는 기존 자동 번역 설정과 관계없이 번역을 시작하지 않으며, 한국어 번역 시작을 누를 때만 선택한 번역 서비스로 원문을 보냅니다.

외부 서비스에 전달되는 것

새 기기에서는 Google 서버 자동 번역이 기본으로 켜집니다. 기존에 자동 번역을 꺼둔 기기는 그 설정을 유지합니다. 새 가사 자동 번역을 끄면 이후 원문을 번역 서버로 보내지 않고 발음만 이용할 수 있습니다. 웹 가져오기와 사진의 발음만 보기는 자동 번역을 시작하지 않습니다.

YouTube선택한 영상 ID와 브라우저 요청 정보. 영상 재생을 위해 YouTube 임베디드 플레이어를 불러옵니다.

LRCLIB검색한 곡명과 아티스트. 공개 가사와 타임스탬프를 찾습니다.

Google 검색일본어/영문 검색 링크를 누르면 곡명·가수 표기와 검색어가 Google로 전달되고 새 탭이 열립니다. 검색 결과의 본문을 자동 추출하지 않으며, 사용자가 복사하거나 사진으로 제공한 원문을 기기에서 발음으로 바꿉니다.
MyMemory / Translated자동 번역을 켠 상태에서 새 가사를 불러오거나 번역 버튼을 누르면 번역할 문장과 언어 쌍, IP 주소 등 통상적인 접속 정보가 직접 전달됩니다. 이후 불러온 가사도 자동 번역합니다. 무료 번역 설정에서 본인 이메일 제공에 체크하고 주소를 저장한 경우, 해당 주소도 번역 요청에 포함됩니다. 다른 방문자의 주소와 공유하지 않습니다. 번역 입력에는 비공개·민감한 정보를 넣지 마세요.
Google 서버 번역자동 번역을 켠 상태에서 새 가사를 불러오거나 번역 시작을 누르면 가사 원문·언어와 통상적인 접속 정보가 Google Apps Script로 전달됩니다. Google의 LanguageApp으로 한국어로 번역하며 이메일은 보내지 않습니다. 이후 불러온 가사도 선택한 방식으로 자동 번역합니다. 반복 요청을 줄이기 위해 번역 결과를 Google 서버에 최대 6시간 캐시하며, 프로젝트 전체의 번역 호출 횟수를 집계합니다. Gmail·Drive의 개인 파일은 읽지 않습니다.
Chrome 기기 번역선택 시 브라우저가 필요한 언어 모델을 내려받습니다. 번역할 문장은 방문자 자신의 기기에서 처리하며 MyMemory에는 보내지 않습니다. 지원되는 PC Chrome에서만 사용할 수 있습니다.
정적 웹 호스팅 제공자사이트 파일 전달에 필요한 IP 주소·브라우저 등 통상적인 접속 정보를 처리할 수 있습니다.

소라미 코드에는 광고 SDK나 별도 방문 분석 도구가 없습니다. 외부 서비스가 처리하는 접속 정보에는 해당 서비스의 정책이 적용됩니다. 소라미는 MyMemory의 번역 등록·공유 API를 호출하지 않습니다.

무료 범위

Google 서버 번역은 일반 Google 계정의 Apps Script 번역 한도인 하루 5,000회 안에서 동작합니다. 소라미에서는 24시간당 최대 4,500회의 새 문장 번역을 처리하도록 제한하며, 방문자들이 이 프로젝트의 한도를 함께 사용합니다. MyMemory의 글자 수 한도와 별개입니다. Google 계정의 다른 스크립트 사용이나 정책 변화로 더 일찍 제한될 수 있습니다.

MyMemory의 익명 사용 한도는 기본 하루 5,000자이며, 본인 이메일을 제공하면 공식 한도는 50,000자입니다. Chrome 기기 번역에는 이 일일 글자 수 한도가 적용되지 않지만 기기의 성능·언어 지원·요청 크기에 따른 제한은 있을 수 있습니다. 같은 네트워크 사용자나 서비스 정책에 따라 이용 가능량이 달라질 수 있습니다. 한도 초과 시 유료 결제로 자동 전환하지 않으며 번역을 멈춥니다. 한글 발음과 이미 저장된 번역은 계속 이용할 수 있습니다. 외부 서비스의 정책과 제공 여부는 변경될 수 있습니다.

지원과 제한

아이패드 Safari와 갤럭시 Chrome에서 사용하는 웹앱입니다. 유튜브 앱이나 다른 탭을 감시하지 않으며 새 노래는 링크로 불러와야 합니다. 유튜브 외부 재생 허용 여부, 가사 제공 여부, 브라우저 정책에 따라 일부 기능이 제한될 수 있습니다. 한글 발음은 일본어·영어·중국어·태국어·스페인어·러시아어·베트남어·프랑스어·독일어·이탈리아어를 지원합니다. 중국어는 표준어이며 성조·강세·지역 발음은 완전히 옮기지 못합니다. 짧은 가사의 감지가 틀리면 가사 언어를 바꿀 수 있습니다. 한자 읽기와 기계 번역은 실제 가창이나 원래 의미와 다를 수 있습니다.
