# 아산집 알리미 푸시 서비스

기존 GitHub Pages 앱의 표준 Web Push 서버입니다. 안드로이드 Chrome/PWA를 기본으로 하며 ChatGPT 알림을 사용하지 않습니다.

- `/api/config`: 공개 VAPID 키와 수집 상태
- `/api/subscribe`: 기기 구독 등록 (기기에서 생성한 임의 토큰)
- `/api/device`: 자신의 연결·발송·표시 확인 상태 / DELETE로 구독 해지
- `/api/test`: 기기 소유자가 요청하는 시험 알림
- `/api/receipt`: 알림 표시 후 HMAC 서명이 있는 확인 기록
- `/api/tick`: 고정된 공개 GitHub 공고 데이터만 확인하고 저장된 알림 발송

GitHub Actions가 수집 직후와 별도 10분 주기로 tick을 호출합니다. 새 공고와 중요 변경은 발견 후 발송하며, 신청 시작과 D-3·D-1·당일 알림을 추가합니다. 확인 실패·90분 이상 오래된 데이터는 하루 한 번 점검 알림을 만듭니다. GitHub 스케줄 자체가 멈추면 자동 발송도 멈추므로 즉시성 또는 100% 수신을 보장하지 않습니다.

D1에 구독, 이벤트, 발송 이력을 저장하고 알림마다 기기별 중복을 방지합니다. 일시적인 발송 실패는 재시도하고 404/410 구독은 제거합니다. 브라우저에서 알림 표시가 완료되면 별도 확인을 남깁니다. 발송 서비스의 수락, 기기 표시, 사용자가 읽는 것은 각각 다릅니다.

`VAPID_PRIVATE_KEY`는 Sites 비밀 환경 변수에만 저장합니다. 키를 임의로 교체하면 기존 기기 재등록이 필요합니다. 구독 URL·토큰을 로그나 공개 저장소에 남기지 마세요. 배포 환경은 `.openai/hosting.json`의 기존 프로젝트를 재사용합니다. D1 스키마 변경은 `npm run db:generate`로 생성한 마이그레이션을 포함해 배포합니다.

검증: `npm test`, `npm run typecheck`, `npm run build`. 테스트는 실제 SQLite SQL과 Web Push 암호화·복호화, 기기 확인, 중복 방지, 재시도, 만료 구독 제거를 확인합니다. 실제 안드로이드 알림창 수신은 앱의 시험 알림으로 확인해야 합니다.
