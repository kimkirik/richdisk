# 아산집 알리미

아산시 임대주택 모집·예비입주자 공고를 조회하는 공개 PWA입니다.

공개 앱: https://kimkirik.github.io/richdisk/asan-rental-watch/

## 안드로이드 앱 알림

1. 안드로이드 Chrome에서 공개 앱을 엽니다.
2. 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가를 선택합니다.
3. 앱의 알림 설정 → 이 기기에서 알림 연결을 누르고 권한을 허용합니다.
4. 자동으로 보내지는 시험 알림이 휴대폰 알림창에 표시되는지 확인합니다.

앱을 닫아도 표준 Web Push로 알림을 받습니다. 회원가입은 필요 없으며 ChatGPT/Codex 알림을 사용하지 않습니다. 기기 권한 허용과 서버 연결, 발송 수락과 기기 표시 확인을 각각 구분합니다. ‘이 기기 알림 끄기’로 서버 구독을 삭제할 수 있습니다.

아이폰·아이패드는 iOS/iPadOS 16.4 이상에서 Safari → 공유 → 홈 화면에 추가 후, 설치된 앱의 아이콘으로 열어 알림 연결을 눌러야 합니다. 일반 브라우저 탭에서는 iPhone 푸시를 연결할 수 없습니다. 기기를 자동 인식하여 설치와 권한 안내를 바꾸며, 다른 기기의 기본 안내는 안드로이드입니다. 집중 모드·알림 요약도 수신 시각과 표시 방식에 영향을 줍니다. 지원 조건: https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/

2026-09-07 운영 검증에서 Cloudflare Workers가 지원하지 않는 `redirect: error`가 실제 발송을 막는 문제를 발견하여 `manual`로 수정했습니다. 3xx는 전달하지 않고 실패로 처리합니다. 수정 후 운영 서버 → Apple Push → macOS Safari 서비스워커 → 알림 표시 확인 API까지 실제 성공했습니다. 이는 Apple 전송 경로 검증이며 iPhone·Android 실물 기기의 수신 확인을 대신하지 않습니다. 해당 휴대폰의 시험 알림을 반드시 확인하세요.

- 공식 사이트를 약 30분마다 확인하고 신규·중요 변경을 발견하면 앱 알림을 보냅니다. GitHub 예약 실행은 지연될 수 있어 실시간·무누락을 보장하지 않습니다.
- 접수 시작일과 마감 3일 전·1일 전·당일에 알립니다. 원문에 정확한 시간이 있으면 그 시각까지 처리합니다.
- 별도 10분 주기 점검이 실패한 발송을 재시도하고, 일부 공식 출처 실패 또는 데이터가 90분 넘게 오래되면 점검 알림을 만듭니다. 스케줄러 자체 장애는 즉시 감지하지 못할 수 있습니다.
- 인터넷 연결, 휴대폰 알림 권한, 배터리 제한, 브라우저 강제 종료 등으로 알림이 늦어질 수 있습니다. 반드시 시험 알림으로 기기를 확인하세요.
- 푸시 서버의 소스와 운영 설명은 `push-service/README.md`를 확인하세요. 비밀키는 서버 환경에만 저장합니다.

## 공식 사이트 수집

- LH청약플러스, 마이홈포털, 아산시청, 충남개발공사, 주택관리공단을 확인합니다.
- LH는 2000년 이후 전국 진행 공고를 페이지 끝까지 확인하고 아산 적용 여부를 상세 원문에서 확인합니다. 제목에 아산이 없는 전국 수시모집도 대상입니다. 페이지·상세 조회가 실패하면 전체 확인 성공으로 보고하지 않습니다.
- 본문 신청 일정·자격·임대조건, 첨부파일 ID, 마감 시각 변경으로 신규·중요 변경을 구분합니다. 같은 첨부파일 ID의 파일 내용만 바뀌거나, 공급지역이 첨부파일에만 있으면 감지하지 못할 수 있습니다.
- 앱을 보는 동안에는 매분 최신 수집 결과를 읽습니다. 휴대폰 알림 발송은 서버에서 담당하여 화면 갱신과 중복되지 않습니다.

## 공고와 오류 보존

- 출처별 확인 결과와 마지막 수집 시도를 표시합니다. 90분 넘게 갱신되지 않으면 지연을 표시합니다. 확인 실패는 '신규 없음'이 아닙니다.
- 마감·취소된 공고는 보관함으로 이동하며 개수 제한으로 삭제하지 않습니다.
- 목록에서 사라졌다는 이유로 모집 종료를 추정하지 않습니다. 기한이 없거나 출처 확인이 실패한 공고는 상태 확인 필요로 남깁니다.
- 공식 출처 확인이 불완전해도 데이터와 오류 현황을 먼저 공개하고, Actions 결과를 실패로 표시하여 운영자가 감지할 수 있게 합니다.
- LH와 마이홈의 공고 ID를 통합합니다. LH 장애 시 포털의 짧은 제목·누락 날짜가 기존 상세 정보를 지우거나 거짓 변경 알림을 만들지 않도록 합니다.
- 검색·유형 필터·마감순 정렬·보관함을 제공하며 모든 공고를 앱 안에서 선택할 수 있습니다. 상세 정리가 없는 공고도 제외하지 않고 원문으로 안내합니다.
- 든든전세 상세 비용·사진·도면 여부는 2026-08-27 공고를 정리한 자료이며 자동 목록 확인이 모든 첨부자료의 재검증을 뜻하지 않습니다.

## 개발 및 검증

Node.js 22.13 이상. 저장소 루트에서:

```bash
cd asan-rental-watch/source
npm ci --ignore-scripts
npm run update:notices
npm test
npm run typecheck
npm run dev
```

`npm run update:notices`는 실제 공식 출처를 조회하고 `../data/notices.json`을 갱신합니다. `ASAN_RENTAL_DATA_FILE`을 지정하면 별도 경로에서 점검할 수 있습니다. 알림은 보내지 않습니다.

```bash
npm run build
npm run publish:static
```

`publish:static`은 검증된 `dist`에서 공개 디렉터리로 정적 파일을 복사하며 기존 소스·수집 스크립트·데이터를 보존합니다. 변경된 소스와 공개 결과물을 함께 커밋해야 GitHub Pages에 반영됩니다. 공고 데이터는 빌드 시 원본 `../data/notices.json`에서 복사합니다.

테스트는 한국시간 마감 경계, 장애 중 보존, 재등장, 중복 제거, 공고 파싱, 백그라운드 푸시 표시와 수신 확인을 검증합니다. 푸시 서버의 테스트는 별도로 실제 SQLite와 표준 Web Push 암호화·복호화, 발송 재시도·만료 구독 제거를 검증합니다.
