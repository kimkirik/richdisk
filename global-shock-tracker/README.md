# 글로벌 충격 트래커

공개 주소: https://kimkirik.github.io/richdisk/global-shock-tracker/

## 2026-09-10 개선

- 신호 기준일과 서버 확인 시간, 15분 자동 확인 주기를 표시합니다. 갱신 실패 시 이전 자료임을 표시하고 재시도할 수 있습니다.
- API 요청은 25초 후 종료됩니다. 잘못된 JSON, 누락된 값, 사건·기간이 다른 응답을 걸러냅니다.
- 차트 기간을 변경하면 이전 기간의 요약을 즉시 비웁니다. 아직 지나지 않은 D+7·D+30·D+90은 미도달로 표시합니다.
- 표에 실제 관측일을 표시합니다. CPI 날짜는 관측월이며 발표일이 아니고, 당시 이용 가능한 정보였다는 의미가 아님을 명시합니다.
- 320px부터 가로 넘침을 방지하고 본문·라벨 가독성, 선택 상태, 키보드 포커스와 요약표 스크롤을 개선했습니다.
- CSS에서 상대 주소로 잘못 해석되던 로고 경로를 앱의 절대 주소로 수정했습니다.
- 알림 설정은 앱 경로별로 격리됩니다. 기존 앱의 서비스워커와 알림 허용이 확인되는 경우 기존 설정과 중복 방지 상태를 이전합니다. 페이지와 워커가 같은 캐시 상태를 사용하며 BTC 알림의 14일 제한을 유지합니다.

## 수정과 검증

기존 저장소에는 배포 번들만 포함되어 있었습니다. `src/app.js`는 해당 번들을 읽을 수 있게 복원한 소스이며, 기존 React·차트·아이콘 라이브러리는 그대로 사용합니다. 서버와 다른 앱은 이 폴더에서 수정하지 않습니다.

별도의 패키지 설치 없이 Node.js로 실행합니다.

```sh
node global-shock-tracker/build.mjs
node --test global-shock-tracker/tests/*.test.mjs
```

빌드는 소스와 보완 스타일에 콘텐츠 해시를 붙여 `assets/`에 저장하고 `index.html` 경로를 갱신합니다. 생성된 파일을 직접 수정하지 마세요. 기존 라이브러리 번들은 보존합니다.

데이터는 기존 공개 서버의 Yahoo·OECD·USGS 등 연결을 사용합니다. 허용된 공개 출처에서 실제 CORS를 확인해야 하므로 로컬 주소만으로는 API 연결 검증이 되지 않을 수 있습니다. 공급처 중단 시 값의 정확성이나 갱신을 보장하지 않습니다. 백그라운드 알림 예약은 기기·브라우저 지원과 권한에 따라 달라지며, 스케줄 등록 성공 여부를 구분해서 안내합니다.
