# 리치 멍TV

강아지가 좋아할 만한 유튜브 영상을 리치의 실제 반응에 맞춰 보여주는 모바일·PC 웹앱입니다.

- 외부 재생이 확인된 강아지용 영상 90개
- 강아지가 구분하기 쉬운 파랑·노랑 중심 UI
- 친구멍, 새·다람쥐, 공놀이, 자연산책, 농장동물, 소리반응 필터
- 리치찜과 꼬리반응 기록에 따른 종류·자극별 맞춤 정렬
- 3분 반응 테스트 타이머와 즉시 시청 종료
- 18개씩 나눠 표시하는 가벼운 목록
- 별도 YouTube API 키 없이 직접 재생
