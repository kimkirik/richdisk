# 카나리아 프로젝트 v3

공개된 기상·지진·환율을 확인하고, 대처 매뉴얼과 비상 준비 체크리스트를 보관하는 정적 웹 앱입니다. 의존성 설치나 빌드 과정 없이 이 폴더를 하위 경로에 배포할 수 있습니다.

## 동작과 한계

- 안전·위험 종합점수를 산출하지 않습니다. 기상 수치만 앱의 참고 기준과 비교하며, 공식 기상청 특보와 구분합니다.
- 각 API 응답의 숫자·단위·시간·구조를 검증합니다. 연결 실패, 누락, 오래된 자료를 0 또는 안전으로 표시하지 않습니다. 실패 시 이전 값과 로딩 표시를 제거합니다.
- 기상 현재값은 Open-Meteo 모델 추정값이며 기온·체감온도·습도·바람·강수량, 앞으로 12시간 및 3일 예보를 표시합니다. 일간 주의 기준은 오늘 전체 예보이므로 지난 시간대도 포함됩니다. 누락된 선택 항목은 따로 표시하며 유효한 기온을 숨기지 않습니다.
- USGS 지진은 목록 생성 시각 기준 최근 24시간의 전 세계 M4.5 이상 지진입니다. 아산의 위험도를 뜻하지 않습니다. 지진이 없으면 최대 규모는 ‘해당 지진 없음’으로 표시합니다.
- Frankfurter v1의 ECB 기준 USD/KRW 참고환율은 영업일에 갱신됩니다. 기본 주소가 실패하면 같은 제공처의 기존 주소로 한 번 더 확인합니다. 실시간 은행 환전 가격이 아닙니다.
- 앱에서 정한 최대 자료 나이: 기온 2시간, 지진 목록 30분, 환율 7일. 사용자의 기기 시계 기준이며, 기관의 품질보증 기준이 아닙니다.
- 화면이 활성 상태일 때 약 5분마다 확인하고, 다시 활성화되면 자료 나이를 검사합니다. 현재 위치 모드에서는 새로고침 시 기기 위치도 다시 확인합니다. 자료별 재시도와 전체 새로고침을 지원합니다. 기본 날씨 조회가 실패하면 같은 제공처의 JMA 모델 주소로 재조회합니다. 제공처 전체 장애까지 해결하는 독립 서비스는 아닙니다.
- 시험 알림만 제공합니다. 자동 감시, 앱 종료 후 위험 알림, 백그라운드 푸시 서버는 없습니다. 실제 대피 지시는 담당 기관에서 확인해야 합니다.
- 준비 상태와 저장 매뉴얼은 이 브라우저의 localStorage에만 보관됩니다. 저장이 차단되면 현재 화면에서만 유지되고 안내가 표시됩니다.
- 첫 서비스워커 설치가 성공하면 매뉴얼을 오프라인에서 열 수 있습니다. API 응답은 캐시하지 않습니다. 서비스워커의 캐시 정리와 알림 클릭은 이 앱 경로에만 적용됩니다.

## 현재 위치 날씨

- 기본 화면은 아산시 중심 좌표(36.7898, 127.0018)로 표시합니다. **내 위치 날씨 보기**를 누르고 위치 권한을 허용하면 기기가 반환한 좌표로 바뀝니다.
- GPS 등 고정밀 위치를 우선 요청하고 위치 획득 실패·시간 초과 시 일반 위치 방식으로 한 번 재시도합니다. 기기 정확도와 위치 확인 시각을 표시합니다. GPS가 없는 기기는 Wi-Fi 등으로 위치를 추정할 수 있습니다.
- 이미 위치 권한을 허용한 브라우저에서는 진입 시 다시 위치를 확인합니다. 위치 좌표는 앱의 영구 저장소에 기록하지 않습니다. 날씨 조회를 위해 위도·경도를 소수점 넷째 자리로 제공처에 전달합니다.
- 위치 권한 거부·기기 위치 서비스 비활성·시간 초과를 구분하며 아산시 또는 마지막으로 확인한 위치의 날씨를 유지합니다. **아산시 기준** 버튼으로 기기 위치 요청을 취소하고 아산시로 돌아갈 수 있습니다.
- 위치 변경 전에 시작된 늦은 날씨 응답은 새 위치 결과를 덮어쓸 수 없습니다.

## 확인과 배포

```sh
node --test canary-signal/tests/*.test.mjs
python3 -m http.server 4173
```

`http://127.0.0.1:4173/canary-signal/`에서 확인합니다. 기존 저장소 루트·다른 앱을 변경하지 않고 `canary-signal/`만 배포합니다. 파일을 변경할 때 `index.html`, `app.js`, `sw.js`의 `?v=`와 서비스워커 캐시 버전을 함께 올려야 합니다.
