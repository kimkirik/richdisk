# 냥이TV

새, 다람쥐, 물고기와 작은 움직임을 고양이의 실제 반응에 맞춰 보여주는 모바일·PC 웹앱입니다.

- 외부 재생 상태를 확인한 고양이용 영상 100개
- 첫 화면에 100개 영상을 더 보기 버튼 없이 한 번에 표시
- 새 구경, 다람쥐·토끼, 물고기, 쥐·작은 사냥감, 편안한 자연 필터
- 기분별 원터치 재생과 안 본 영상을 골라주는 `냥이 픽`
- 냥이찜과 눈·앞발 반응 기록에 따른 맞춤 정렬
- 최근 시청 영상 기억 및 카드의 `봤어요` 표시
- 3분 반응 테스트 타이머와 즉시 시청 종료
- 별도 YouTube API 키 없이 직접 재생
