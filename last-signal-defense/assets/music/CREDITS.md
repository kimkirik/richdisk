# Last Signal — orchestral score

Original 24-bar D-minor composition and arrangement, created for this game. The three synchronized 48-second stems use 120 BPM and remain at their musical tempo at every game speed.

- `foundation.mp3`: string ensemble, cello, double bass and a French horn theme.
- `battle.mp3`: spiccato string ostinatos, timpani, orchestral bass drum, marching snare and cymbals.
- `boss.mp3`: additional horns, trombones, high strings and percussion accents.

Instrument recordings: VSCO 2 Community Edition by Versilian Studios / Sam Gossner, including the VSCO 1 percussion included in that distribution. The source library is dedicated under CC0 1.0. These recordings were arranged and mixed into original music; no existing soundtrack was copied.

Source: https://github.com/sgossner/VSCO-2-CE
License and library information: https://versilian-studios.com/vsco-community/
CC0: https://creativecommons.org/publicdomain/zero/1.0/

All runtime audio is served from this game's own assets. No streaming service or external audio API is required.
# Victory / final transmission

`victory.mp3` is an original eight-second D-major victory fanfare, composed for the sector celebration and final campaign transmission using the same CC0 VSCO 2 Community Edition recordings. Horns, strings, trombone, timpani, snare, and cymbal resolve the battle score into a sustained final chord. It is hosted locally and does not require an external streaming service.
