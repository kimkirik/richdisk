# 톡톡! 네온 발바닥

반려동물이 태블릿 화면을 누르면 360도로 회전하는 네온 발바닥과 보호자가 녹음한 이름 음성이 겹쳐 재생되는 설치형 웹앱(PWA)입니다.

## 실행 주소

https://kimkirik.github.io/richdisk/neon-paw-play/

## 사용 방법

1. 반려동물 이름을 입력합니다.
2. 마이크 권한을 허용하고 이름을 한 번 녹음합니다.
3. `START`를 누른 뒤 화면을 톡톡 누릅니다.
4. 종료할 때는 오른쪽 위 `길게 눌러 나가기`를 약 2초간 누릅니다.

녹음은 기기 메모리 안에서만 사용하며 서버로 전송하지 않습니다. 외부 라이브러리나 외부 API를 사용하지 않으며, GitHub Pages의 HTTPS 환경에서 실행됩니다.

마이크 기능은 보안 정책상 HTTPS 주소에서만 작동합니다. Android Chrome에서는 설치 버튼이나 브라우저 메뉴의 `앱 설치`를, iPhone/iPad Safari에서는 공유 메뉴의 `홈 화면에 추가`를 사용하세요.
