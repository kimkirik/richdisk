# 끼리끼리 날씨·물때 정확도 점검

점검일: 2026-09-06 (한국시간). 대상: 꾸지나무골 해수욕장과 공통 자료 처리 로직.

## 솔직한 평가

화면 구성과 장소·달력 기능은 커뮤니티에서 쓰기 좋은 출발점입니다. 그러나 API 연결 성공과 예보 정확성은 다른 문제입니다. 기존 버전은 누락된 날씨를 임시 숫자로 채우고, 인근 기준항 자료를 현지 물때처럼 받아들이기 쉬워 정확도 중심의 수정이 필요했습니다.

## 확인한 문제와 수정

| 문제 | 수정 |
|---|---|
| 꾸지나무골 좌표 36.85, 126.18은 태안군 안내 좌표에서 약 13.3km 떨어져 있음 | 태안군 좌표 36.9353909, 126.2843977 적용. 기상청 격자 48,113으로 변환 |
| 기온·풍속 누락 시 24℃·2.5m/s 등 임시값 사용 | 필수 항목이 없는 날씨는 미확인 처리 |
| 간조 시간대 예보가 없으면 다른 시간대로 대체 | 실제 예보가 제공된 시간만 사용하고 표시 |
| 예보 1페이지 1,000건 이후 자료 누락 가능 | 필요한 날짜까지 페이지 조회 |
| 빈 물높이가 0cm로 바뀌거나 알 수 없는 고저조 구분을 고조로 처리 | 결측·잘못된 시각·구분 제외, 불완전 조석 자료 미확인 |
| 부분적인 강수량을 하루 총량으로 해석 | 24시간이 모두 확인된 경우에만 합계 표시. 강수 구간값은 상한으로 표시 |
| 날짜 변경·조회 실패 후 이전 수치가 남을 가능성 | 선택값과 응답 일치 확인, 갱신 중 기존 수치 제거, 5분 및 화면 복귀 시 재조회 |
| 초기 접속 때 사용하지 않는 22일 자료 선조회 | 해당 선조회 제거 |
| 자체 지수를 안전 판정으로 오인 가능 | 자체 계산 참고지수와 간조 전후 참고 시간임을 명시 |
| 서비스워커가 같은 도메인 다른 앱 캐시까지 삭제 | 이 앱 이름의 캐시만 정리 |

## 물때 대조의 한계

2026-09-06 조회 당시 앱의 태안 기준점 예보는 간조 05:08 / 17:19, 기상청 꾸지나무골 페이지는 05:14 / 17:26이었습니다. 오전 6분, 오후 7분 차이입니다. 높이도 각각 322/218cm와 326/227cm로 달랐습니다. 이는 서로 다른 기준 자료의 차이이며, 현장 실측 오차를 검증한 결과가 아닙니다.

특정 날짜의 차이를 모든 날짜에 일괄 더하는 보정은 하지 않았습니다. 화면에 인근 기준점, 자료 출처, 조회 시각과 공식 비교 링크를 표시했습니다. 현지 물때 정확도를 더 높이려면 공식 지점의 장기 예보 자료 또는 검증된 보정계수가 필요합니다. 날씨 예보 적중률이나 안전성을 수치로 보장할 근거도 없습니다.

## 검증

- 서버 자동 검증 27개 통과 및 TypeScript 검사 통과. 화면과 서버 빌드 성공.
- 로컬 점검용 응답으로 날짜 전환 중 이전 숫자 제거, 새 날짜 수치 표시, API 503 실패 후 수치 숨김을 브라우저에서 확인. 이 응답은 화면 동작 확인용이며 실제 예보 정확도 검증용이 아닙니다.
- 메인·달력 화면을 모바일 390px와 PC 1440px에서 확인. 가로 넘침 없음, 확인한 이미지 정상, 달력 왕복 주소 정상, 확인한 흐름의 앱 콘솔 오류 없음.
- 매니페스트·아이콘·서비스워커는 `/richdisk/kkirikiri-haerugil/` 기준 경로 유지. 실제 기기 설치·오프라인·장기 사용 검증은 별도입니다.
- GitHub 변경은 `kkirikiri-haerugil/` 안으로 제한. API 키는 공개 화면 소스에 추가하지 않음.
- 수정 API의 운영환경 연결 및 GitHub Pages 반영 결과는 공개 반영 후 최종 확인 대상입니다.
