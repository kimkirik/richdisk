- 공개 주소: <https://kimkirik.github.io/richdisk/kkirikiri-haerugil/>
- 배포 기준 경로: `/richdisk/kkirikiri-haerugil/`
- 실시간 물때·날씨 API: `https://haerugil-guide.kimkirik.chatgpt.site/api/conditions`
- API 키와 서버 비밀값은 이 공개 저장소에 포함하지 않습니다.

GitHub Pages는 서버 코드를 실행하지 않으므로, 화면은 위의 공개 API에서 최신 공공데이터를 읽습니다. 화면 코드는 GitHub Pages에서 서버 런타임 없이 동작하도록 Vite 기반 정적 파일로 빌드했으며, `assets/`에는 브라우저용 JavaScript와 CSS만 들어 있습니다.

## 재빌드

`source/`에는 비밀값 없는 화면 소스만 보관합니다. Node.js 24 이상에서 `cd source`, `npm ci`, `npm run typecheck`, `npm test`, `npm run build` 순서로 실행합니다. 빌드는 이 앱 폴더의 HTML과 새 assets 파일만 갱신하며 기존 다른 앱은 변경하지 않습니다. API 서버 수정은 별도 Sites 소스 저장소에서 관리합니다.

## 자료 해석

- 날씨는 실제 제공된 예보 시각과 발표 시각을 표시합니다. 결측을 기온 24℃, 풍속 2.5m/s 등으로 채우지 않습니다.
- 물때는 화면에 표시된 기준점의 조석예보입니다. 인근 항구 예보는 선택 해변의 현지 물높이를 보장하지 않습니다.
- 참고지수와 간조 전후 시간은 자체 계산이며 안전 판정이 아닙니다.
- 강수 구간값은 상한을 표시하고, 하루 24시간이 모두 있을 때만 일합계를 표시합니다.
- 화면은 5분마다, 다시 활성화할 때 갱신합니다. 날씨·참고점수는 재실행 때 복원하지 않습니다.
- 확인된 물때만 날짜·장소별 최대 6시간, 최대 24건 저장합니다. 재실행 즉시 물높이와 원자료 조회 시각을 표시하고 최신 자료를 확인합니다. 임시 기준항 표시와 결측·잘못된 날짜는 저장하지 않습니다.
- 서버는 같은 기준항·날짜의 검증된 물때를 10분 동안 공유하며, 좌표형 조회와 기준항 조회를 동시에 진행합니다.

정확도 점검의 근거와 범위는 `ACCURACY-REVIEW.md`를 참고하세요.
